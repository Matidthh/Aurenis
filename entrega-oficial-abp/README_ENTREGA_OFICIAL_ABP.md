## 🖨️ INSTRUCCIONES PARA EXPORTACIÓN / IMPRESIÓN A FORMATO PDF OFICIAL

Para generar el **PDF Oficial Consolidado**:
1. Abrir el archivo `dossier-print-template.html` en cualquier navegador web moderno (Google Chrome, Firefox o Edge).
2. Presionar `Ctrl + P` (o `Cmd + P` en macOS).
3. Seleccionar **"Guardar como PDF"**.
4. En opciones de configuración:
   - **Diseño:** Vertical (Portrait)
   - **Tamaño de papel:** A4 o Carta (Letter)
   - **Márgenes:** Personalizados o Predeterminados (el archivo incluye márgenes `@page` CSS milimétricos)
   - **Opciones:** Marcar *"Gráficos de fondo"* para conservar las portadas, insignias y paleta institucional.
5. Hacer clic en **Guardar** para obtener el documento PDF consolidado con portada institucional e índice interactivo.
